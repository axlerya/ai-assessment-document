# document-worker

Сервис обработки неструктурированных документов юридического характера: извлечение
текстового слоя или OCR, нормализация, разбиение на страницы и chunks.

## Запуск стека

```bash
cd document-worker
docker compose up -d --build
```

Поднимаются PostgreSQL, RabbitMQ, MinIO, разовые задачи миграций и создания
бакета и сам воркер. Воркер стартует только после того, как обе разовые задачи
завершились успешно: сервис без схемы или без бакета не работает, и падать он
должен на развёртывании, а не на первом документе.

Готовность — `http://localhost:8080/health/ready`, панель брокера —
`http://localhost:15672` (`document_worker` / `change-me`).

Настройки перечислены в [.env.example](.env.example). Пароли в compose-файле
пригодны только для локального запуска.

## Тесты

```bash
uv run pytest                      # всё, кроме сборки образа
uv run pytest -m unit              # без внешних зависимостей
uv run pytest -m slow              # сборка и проверка образа
```

Интеграционные тесты поднимают контейнеры сами — нужен работающий Docker.
